# EduFlow - Complete Education ERP System

A comprehensive Education ERP (Enterprise Resource Planning) system built with Next.js 14, TypeScript, and Tailwind CSS. This system provides multi-tenant architecture supporting super admins, school administrators, teachers, students, and parents with role-based access control.

## 🌐 Application Flow

### Main Landing Page (`/`)
**URL**: `https://eduflow.com` or `http://localhost:3000`

The main landing page serves as the entry point to the EduFlow platform. It features:
- **Interactive Hero Section** with platform statistics
- **Feature Showcase** with hover effects and auto-rotation
- **Portal Access Cards** for different user types
- **Testimonials** from real schools
- **Call-to-Action** sections for getting started

**Navigation Options:**
- **Super Admin Portal** → `/admin`
- **Student Portal** → `/portal` 
- **School Admin** → `/admin-login`
- **Demo Access** → Various demo links

### School-Specific Landing Pages
**URL Pattern**: `https://[school].eduflow.com` (e.g., `oakwood.eduflow.com`)

When accessed via school subdomain, the same page (`/`) automatically detects the school and shows:
- **School Branding** with logo and colors
- **School Information** (stats, programs, achievements)
- **Admissions Portal** access
- **Student/Staff Login** options
- **Contact Information** specific to the school

## 🔐 Authentication Flow

### 1. Super Admin Authentication (`/admin`)
\`\`\`
User visits /admin
↓
Enters credentials (must contain "superadmin" or "admin@system")
↓
AuthContext validates credentials
↓
If valid: Redirect to /admin/dashboard
If invalid: Show error message
\`\`\`

**Test Credentials:**
- Email: `superadmin@eduflow.com`
- Password: `admin123`

### 2. School Admin Authentication (`/admin-login`)
\`\`\`
User visits /admin-login
↓
Enters school admin credentials
↓
AuthContext validates credentials
↓
If valid: Redirect to /dashboard
If invalid: Show error message
\`\`\`

**Test Credentials:**
- Email: `admin@school.com` (any email without "superadmin")
- Password: `admin123`

### 3. Student Portal Authentication (`/portal`)
\`\`\`
User visits /portal
↓
Enters Student ID + Date of Birth
↓
System validates student credentials
↓
If valid: Show academic results
If invalid: Show error message

## 🎯 User Roles & Permissions

### Super Admin
**Access Level**: Platform-wide
**Capabilities**:
- Manage all schools on the platform
- Create and configure new schools
- Manage subscription plans and billing
- View platform-wide analytics
- Manage super admin accounts
- System configuration and settings

### School Admin
**Access Level**: School-specific
**Capabilities**:
- Complete student lifecycle management
- Teacher and staff management
- Academic structure (classes, subjects, departments)
- Assessment creation and grading
- Attendance tracking and reporting
- Fee management and payment tracking
- Internal communication system
- Generate academic and administrative reports

### Teacher
**Access Level**: Limited school access
**Capabilities**:
- View assigned classes and students
- Mark attendance for assigned classes
- Create and grade assessments
- Communicate with students and parents
- View academic calendar and events

### Student
**Access Level**: Personal academic data
**Capabilities**:
- View academic results and grades
- Check attendance history
- View fee payment status
- Access school announcements
- Download report cards

### Parent
**Access Level**: Children's academic data
**Capabilities**:
- Monitor children's academic progress
- View attendance and behavior reports
- Communicate with teachers
- Track fee payments
- Receive school notifications

## 🚀 Getting Started

### Prerequisites
- Node.js 18 or higher
- npm or yarn package manager
- Modern web browser

### Installation
\`\`\`bash
# Clone the repository
git clone https://github.com/your-org/eduflow.git

# Navigate to project directory
cd eduflow

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser and navigate to
http://localhost:3000
\`\`\`

### Environment Setup
Create a `.env.local` file in the root directory:
\`\`\`env
NEXT_PUBLIC_API_URL=http://localhost:3001/api
NEXT_PUBLIC_APP_URL=http://localhost:3000
DATABASE_URL=your_database_connection_string
JWT_SECRET=your_jwt_secret_key
PAYSTACK_PUBLIC_KEY=your_paystack_public_key
PAYSTACK_SECRET_KEY=your_paystack_secret_key
\`\`\`
